# Client site template

A one-page website for therapists, healers, coaches and small practices, with a hidden offers page, privacy policy, contact form and newsletter sign-up. It is plain HTML and CSS, hosted free on Cloudflare Workers and edited by talking to Claude.

| Read | For |
|---|---|
| `SETUP.md` | You: the Zoom setup flow, with a diagram |
| `INTAKE.md` | The client: questions to answer before the call |
| `EDITING.md` | The client: how to make changes afterwards |
| `CLAUDE.md` | Claude: the rules it follows when editing |

Placeholders look like `[[THIS]]`. A site is ready when a search for `[[` finds nothing.
